# 3. 프로젝트 소개

꿈끼리AI는 AI를 단순히 새로운 기술로 소개하는 데 그치지 않고, 각자의 꿈과 일상 속 문제를 해결하는 실용적인 도구로 활용하도록 돕는 브랜드임.

꿈끼리AI의 실제 활동은 다음과 같음.

- AI 도구를 활용해 업체의 홍보 영상을 제작함.
- 업체가 AI를 업무에 도입하고 활용할 수 있도록 도움.
- AI 활용 방법에 관한 강연과 교육을 진행함.
- AI 재능기부를 통해 마련한 기부금을 나눔에 사용함.
- 후원단체 학생들에게 새 학기 신발을 지원함.
- 자폐 아이를 위한 후원금을 전달함.
- AI 활용이 사람의 꿈과 새로운 시작으로 이어질 수 있음을 알림.

본 영상은 위 활동을 바탕으로 `AI 활용 → 교육과 재능기부 → 실제 후원 → 브랜드 메시지`의 흐름을 시각화하였음.

# 6. 과제 의도와 제작 방향

이번 과제의 목적은 단순히 AI로 영상 한 편을 생성하는 것이 아니라 다음의 전체 제작 과정을 직접 설계하고 설명하는 데 있음.

```text
브랜드 기획
→ 스토리보드 작성
→ 이미지 프롬프트 설계
→ 기준 이미지 생성
→ 비디오 프롬프트 설계
→ 영상 생성
→ 생성 결과 검토
→ 프롬프트 수정
→ 재생성
→ AI 음성 생성
→ CapCut 통합 편집
→ 최종 검수
```

본 프로젝트에서는 특히 다음 문제를 해결하는 데 집중하였음.

- 생성 결과가 실제 브랜드 활동과 다르게 표현되는 문제
- 꿈끼리 캐릭터의 형태와 화풍이 달라지는 문제
- AI 활용과 후원의 연결 관계가 영상에서 보이지 않는 문제
- 한글 자막이나 로고가 AI 영상 안에서 왜곡되는 문제
- 짧은 영상 안에서 브랜드 메시지를 전달해야 하는 문제
- 화면 자막 없이도 영상과 나레이션으로 내용을 이해시켜야 하는 문제

# 12. 자막을 사용하지 않은 이유

초기 편집에서는 화면 카피와 자막을 추가하는 방안을 검토하였으나, 최종 영상에서는 자막을 제거하였음.

그 이유는 다음과 같음.

- 영상의 길이가 짧아 자막을 읽는 동안 주요 시각 요소를 놓칠 수 있었음.
- 각 장면에 여러 활동이 포함되어 있어 자막까지 추가하면 화면이 복잡해질 수 있었음.
- 나레이션이 영상의 핵심 메시지를 충분히 설명한다고 판단하였음.
- 꿈끼리 캐릭터와 따뜻한 수채화 배경을 중심으로 브랜드 분위기를 유지하고자 하였음.
- 실제 브랜드 소개 및 강연에서 영상 자체를 감성적인 도입 자료로 활용하고자 하였음.

마지막 장면에는 꿈끼리 캐릭터를 중심에 배치하고, 나레이션으로 `꿈끼리AI`라는 브랜드명을 직접 들려주어 브랜드 인지 장치로 활용하였음.

> 과제 검수의 명확성을 높이기 위해 필요할 경우 마지막 장면에만 꿈끼리AI 로고 PNG를 추가할 수 있음. 이는 전체 자막 추가가 아니라 브랜드 인지 장치에 해당함.

## 파일명 정리 원칙

- 파일명에 `(2)`를 사용하지 않음.
- 파일명에 `...`을 사용하지 않음.
- 날짜와 시간만 있는 파일명은 사용하지 않음.
- 같은 파일을 수정하면 V01, V02처럼 버전을 올림.
- 마크다운 파일에는 반드시 `.md` 확장자를 사용함.
- 최종본과 중간본을 이름으로 구분함.
- 과제 제출용과 실제 브랜딩용을 분리함.

# 24. 최종 제작 결과

본 프로젝트는 꿈끼리AI의 실제 활동인 AI 영상 제작, 업체 AI 도입 지원, AI 강연과 교육, 재능기부 및 후원을 하나의 브랜드 영상으로 표현하는 것을 목표로 하였음.

최초 생성 영상은 꿈끼리가 그림을 그리고 아이에게 선물과 하트를 전달하는 일반적인 기부 장면으로 표현되어 실제 브랜드 활동과 차이가 있었음.

이를 개선하기 위해 프롬프트에 다음 내용을 구체적으로 추가하였음.

- AI를 활용한 업체 영상 제작
- 업체의 AI 도입 지원
- AI 강연과 교육
- 학생들의 새 학기 신발 지원
- 아동 지원을 위한 후원
- AI 활용과 나눔의 선순환
- 꿈끼리AI 브랜드 메시지

최종 영상에서는 화면 자막을 제거하고, 캐릭터와 장면의 흐름에 집중하도록 구성하였음. AI 나레이션을 통해 각 씬의 의미를 연결하고 마지막에 꿈끼리AI라는 브랜드명을 직접 전달하였음.

이를 통해 AI를 단순한 기술이 아니라 사람의 꿈과 새로운 시작을 돕는 도구로 활용한다는 꿈끼리AI의 브랜드 방향을 영상으로 구현하였음.
