2. 기술적 설명 및 제작 과정 요약

이번 브랜드 광고 영상은 텍스트 프롬프트를 기반으로 이미지, 영상, 오디오를 각각 생성형 AI로 제작한 뒤 편집 도구에서 통합하였습니다.

기획: 10초 이내 광고를 위해 '도입(AI 재능기부) ➔ 실천(신발/후원금) ➔ 마무리(브랜드)'의 3개 씬으로 구성.

이미지: ChatGPT(DALL-E 3)를 통해 16:9 비율의 따뜻한 파스텔 3D 스타일 키 비주얼 생성. (꿈끼리 캐릭터 일관성 유지)

비디오: 확정된 이미지를 Kling(또는 Gemini)의 기준 이미지로 사용하여 부드러운 애니메이션 모션 생성. (텍스트는 편집 단계에서 삽입)

오디오: Suno AI로 감동적이고 희망찬 분위기의 BGM 생성 및 선정.

편집: CapCut에서 씬별 컷 편집, 자막/브랜드명 삽입, 영상-음악 타이밍 조정 후 최종 출력.

The cute pastel purple elephant 'Kkum-ggiri' happily presenting a beautiful new pair of sneakers wrapped as a gift to a joyful young child. Warm emotional lighting, simple clean pastel background.
